# Garbage Classification — Internship Week 2

This repository contains the second-week internship notebook for the garbage-classification work.

## Project workflow
The main artifact is `WEEK 2 GARBAGE(Internship).ipynb`. Open it in Jupyter Notebook, JupyterLab, or Google Colab and execute the cells in order.

## Setup checklist
1. Use a compatible Python environment.
2. Install the libraries imported by the notebook (review its import cells before installing dependencies).
3. Make sure the required image dataset is available in your environment.
4. Update any machine-specific dataset paths before running the notebook.
5. Review the evaluation output and document metrics only when they are produced by a reproducible run.

## Reproducibility
- Keep dataset paths configurable rather than tied to one computer.
- Do not commit datasets, credentials, or large generated artifacts unless they are required and licensed for redistribution.
- Record Python/library versions and random seeds when reporting results.
